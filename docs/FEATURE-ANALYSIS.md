# Фиче-анализ для FlipDAW

Русскоязычный аналитический документ по итогам исследования GitHub-репозиториев, веб-синтезаторов/секвенсоров/драм-машин и сэмпл-датасетов. Цель — определить, какие фичи подходят FlipDAW и в какие милистоуны их интегрировать.

---

## 1. Что стоит брать (прямые фичи)

### 1.1 Драм-машина / степ-секвенсор (→ M5 timeline / новый модуль)

**drumhaus** — самый богатый референс-набор:
- 8 голосов × 16 шагов, цепочки вариаций A/B/C/D (до 8 баров);
- per-step **velocity / flam / ratchet / accent**;
- микро-ткайминг на голос;
- per-voice HP/LP фильтры, decay, pan, pitch, mute/solo;
- мастер-шина HP/LP, сатурация, фазер, реверб, компрессор;
- пресеты, экспорт WAV через оффлайн-рендер;
- шаринг через 200-символьный URL.

> Лицензия CC BY-NC-SA 4.0 — несовместима с MIT. Копируем только концепции, не код.

**Веб-драм-машины** (по листам hiphopmakers, Virtual Drumming, Pattern Sketch, WebAudio Drum Machine, iO-808):
- 16-ступ грид, пресеты паттернов (Rock/HipHop/Latin);
- **humanize** (рандомизация нот для человечности);
- chain паттернов, **drum fills**;
- tune per-drum (питч на каждый инструмент);
- подписи 3/4 и 12/8.

**Drum Loop Studio**:
- per-step **probability** (75/50/25%), **ratchet** ×2/×3/×4;
- драг-пейнтинг шагов, right-click velocity, alt-click ratchet;
- свинг, SONG mode (чейн паттернов), генератор жанров, autosave.

**orDrumbox v2**:
- независимая длина лупа на дорожку → **полиритмии**;
- евклидовы ритмы, свинг/groove per-track;
- генератор паттернов (регенерит одну дорожку, сохраняя остальные), автобас-линия;
- встроенный синтезатор (3 VCO + ADSR + резонансные фильтры + LFO);
- импорт своих сэмплов в киты;
- экспорт WAV + MIDI.

> Лицензия GPL v3 — снова только концепции.

### 1.2 Нарезка сэмплов (→ M1/M3)

- **wave-slicer**: drag-and-drop, выделение региона на волне, запись в сэмплы, экспорт zip. Паттерн ложится на наш `timeline/pen.ts`.
- **Loopino** (brummer): трим по клип-маркам, неразрушающий fade-out, питч-трекер, «Micro Loop Generator», экспорт WAV «в выбранной тональности», фильтры-эмуляции (ACID-18, Wasp, SEM12), velocity curves.

### 1.3 Генерация / помощь в создании

- **pattrns** (AGPL — не копировать код): архитектура Rhythm→Gate→Emitter, TidalCycles mini-notation, live-coding на Lua. Идея для FlipDAW: генераторы паттернов по нотации (`bd sn bd bd`).
- **aciduino**: евклидов генератор, гармонизатор бас-линий, генеративный движок.
- **Eigentechno**: PCA по ~50 часам лупов — исследование, не фича. Сигнал к идее «генератора лупов на статистике».

### 1.4 Синт-движки

- **Vaporizer2**: гибридный вейвтейбл-синтез (additive + subtractive), alias-free, редактор вейвтейблов с Bezier draw. Для FlipDAW: простой вейвтейбл-редактор в M5.
- **TinyMusic**: секвенсор на строковых нотах `'G3 q'` — удобный бекстейдж-формат паттерна.

### 1.5 MIDI / аппаратка (→ M4, OSC/MIDI уже есть)

- **Coda-88**: 3 velocity-слоя, звук релиза, демифер — пример карты «MIDI нота → набор WAV».
- **ESP32_SD_Sampler**: киты читаются с FAT32 по FAT (15–20 голосов), `SAMPLER.INI` — человекочитаемая карта сэмплов (`template=<NAME><OCTAVE>v<VELO>`, per-note ADSR, speed). Подход «самплер-на-диске» совпадает с нашей схемой `project.json` + `samples/`. Идея: FlipDAW-совместимый kit-манифест по образцу `SAMPLER.INI`.
- **aciduino / OTTO / roland50 / virtualrhythmbox**: пресеты классических ритм-боксов (TR-330, FR-2L, DR-55, TR-808) — готовые базовые паттерны для бэкстейджа.

### 1.6 Самплерные ромплеры

- **ROMPlayer** (AudioKit): AKSampler, SFZ, velocity layers. Минимальное подмножество SFZ (глобальные регионы, velocity layer, loop points) реализуемо поверх наших ClipPlayer.
- **WebAudioFont**: 1000+ инструментов, wavetable-буферы, queueWaveTable, струминг аккордов, 10-band EQ. Идея: «синт-голоса без аудиофайлов» для демо-треков.

### 1.7 Продакшн / перформанс

- **giada**: Action Editor (сонг-режим), live recorder, VST FX host — проверенные решения для луп-стэпла.
- **loop-drop-app**: **beat repeat**, авто-луп всего, что играешь. Проект заброшен, но концепция рабочая.
- **helio-sequencer**: **версионирование проекта** (git-like), микротональность, паттерн/линейный гибрид, перестраиваемые слои планшета.

## 3. Предлагаемая дорожная карта фич

1. **M5.5 (низкий приоритет)**: степ-секвенсор в timeline — velocity/flam/ratchet/probability, swing, humanize, чейнинг паттернов (по drumhaus / Drum Loop Studio).
2. **M1 (быстро)**: самплер-нарезка по типу wave-slicer + kit-манифест (`kit.json`, по образцу `SAMPLER.INI`).
3. **M4–M5**: синт-голоса «wavetable-буферы без файлов» (WebAudioFont-подход) для демо-треков.
4. **Генераторы**: евклидов ритм-генератор + пресеты классических ритм-боксов.
